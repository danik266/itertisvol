# IT Ertis Volunteer 🌿

Веб-платформа для объединения волонтёров и организаций Павлодара.

## Запуск проекта

```bash
# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000)

## Страницы

| Страница | Путь | Описание |
|----------|------|----------|
| Главная | `/` | Главная страница с баннером, направлениями, мероприятиями |
| Авторизация | `/auth` | Регистрация и вход |
| Анкета | `/quiz` | 7 вопросов → определение направления волонтёрства |
| Организации | `/organizations` | Список с фильтрами, заявки |
| Направления | `/directions` | Все 6 направлений |
| Новости | `/news` | Лента новостей + мероприятия |
| Генератор | `/tasks` | AI-генератор контента |
| Кабинет | `/cabinet` | Профиль, заявки, мероприятия |
